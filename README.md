# Higgsfield AI Studio Clone

A polished frontend recreation of a Higgsfield-style AI video generation studio, built for the 8x Careers assignment.

## Live Demo

https://higgsfield-clone-ten.vercel.app/

## GitHub

https://github.com/akshitalanjewar/higgsfield-clone

## Features

- Cinema Studio generation workflow
- AI model selection
- Prompt and negative prompt controls
- Aspect ratio selection
- Duration and quality controls
- Seed controls
- Camera movement controls
- Lens and aperture controls
- Image/video generation simulation
- Generation progress state
- Gallery with generation history
- Like and delete gallery items
- New Generation reset workflow
- Marketing workspace
- Soul ID workspace
- Upscale workspace
- Responsive dark studio interface

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide React
