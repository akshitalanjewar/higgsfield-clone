### How the Capture Flow Works

```
User submits prompt
       │
       ▼
[PreInvocation hook]
  • Antigravity pipes metadata (conversationId, transcriptPath, modelName) to stdin.
  • capture.py discovers or opens the session log: .agent-logs/<YYYY-MM-DD_HH-MM-SS>_<conversationId>.md
  • Reads transcript.jsonl, extracts the raw user prompt verbatim from <USER_REQUEST>,
    and appends [LOG_ENTRY type=PROMPT num=N ...] if not yet logged.
  • Outputs `{}` to stdout.
       │
       ▼
Agent Execution Loop
  • Model thinks, calls tools (run_command, view_file, etc.)
  • All tool invocations and intermediate chain-of-thought are ignored.
       │
       ▼
[PostInvocation / Stop hook]
  • Fires when the model completes its final response and all tools are idle.
  • Reads transcript.jsonl, extracts the final agent text response verbatim.
  • Appends [LOG_ENTRY type=RESPONSE num=N ...] to the session log.
  • Updates frontmatter (total_exchanges, last_prompt_time).
  • Outputs `{}` to stdout.
```
